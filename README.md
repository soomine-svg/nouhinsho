# 納品書作成システム

卸の納品書を作るための、単体HTMLアプリです。

- 取引先ごとの卸率、その先のお届け先ごとの卸率（2階建て）に対応
- 発注書の画像を画面の横に出したまま入力できます
- 発注書の文字の読み取り（ブラウザの中だけで動きます。外部サービス不要）
- A4での印刷・PDF保存

## 使い方

公開ページを開いて、「④ 使い方」タブをご覧ください。

## データについて

取引先・商品などの台帳は、**このリポジトリには含まれていません。**
使う方のブラウザの中だけに保存され、どこにも送信されません。
バックアップと引っ越しは、アプリ内の「③設定 → E」からファイルで行います。
